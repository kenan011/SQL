SQL DƏRS 3: EV TAPŞIRIĞI
Mövzu: CASE WHEN, NVL, NVL2

Bütün tapşırıqlar FreeSQL-də HR cədvəlləri üzərində yazılır.
Cədvəl adını həmişə HR. ilə yazın, məsələn: HR.EMPLOYEES.
Hər sorğunu işlədib nəticəsini yoxlayın, sonra hamısını bir .sql faylında
öz qovluğunuzdakı ders_03 qovluğuna yükləyin.
Hər sorğunun üstündə şərh kimi tapşırığın nömrəsini yazın: -- Task 1

İstifadə olunan cədvəllər:
HR.EMPLOYEES     işçilər
HR.DEPARTMENTS   şöbələr
HR.JOBS          vəzifələr (MIN_SALARY və MAX_SALARY: vəzifə üçün maaş aralığı)
HR.LOCATIONS     ofislər (şəhər, ölkə kodu)

Cədvəllər bu sütunlarla birləşir:
HR.EMPLOYEES.DEPARTMENT_ID  = HR.DEPARTMENTS.DEPARTMENT_ID
HR.EMPLOYEES.JOB_ID         = HR.JOBS.JOB_ID
HR.DEPARTMENTS.LOCATION_ID  = HR.LOCATIONS.LOCATION_ID

Tapşırıqda "Sütunlar" yazılıbsa, nəticədə məhz bu sütunlar və bu adlar olmalıdır.
CASE-in qaytardığı mətnləri tapşırıqda yazıldığı kimi yazın, məsələn 'Asagi'.


============================== ASAN ==============================

Task 1.
HR.EMPLOYEES cədvəlindən hər işçinin maaş səviyyəsini göstərin:
- maaş 6000-dən azdırsa 'Asagi'
- maaş 6000 ilə 12000 arasındadırsa (hər ikisi daxil) 'Orta'
- maaş 12000-dən çoxdursa 'Yuksek'
Sütunlar: FIRST_NAME, LAST_NAME, SALARY, MAAS_SEVIYYESI


Task 2.
HR.EMPLOYEES cədvəlindən hər işçinin vəzifəsini Azərbaycan dilində göstərin.
Simple CASE ilə yazın (JOB_ID CASE-dən sonra bir dəfə yazılsın):
- IT_PROG   -> 'Proqramci'
- SA_REP    -> 'Satis numayendesi'
- ST_CLERK  -> 'Anbar iscisi'
- qalanları -> 'Diger'
Sütunlar: FIRST_NAME, JOB_ID, VEZIFE


Task 3.
HR.EMPLOYEES cədvəlindən hər işçi üçün komissiya alıb-almadığını göstərin:
- COMMISSION_PCT boşdursa 'Komissiya yoxdur'
- boş deyilsə 'Komissiya var'
Bunu iki dəfə yazın: əvvəl CASE ilə, sonra NVL2 ilə. İki sorğunun nəticəsi eyni olmalıdır.
Sütunlar: FIRST_NAME, COMMISSION_PCT, KOMISSIYA_STATUSU


============================== ORTA ==============================

Task 4.
HR.LOCATIONS cədvəlindən hər ofisin hansı qitədə olduğunu göstərin:
- ölkə kodu US, CA, MX, BR olanlar      -> 'Amerika'
- ölkə kodu UK, DE, IT, NL, CH olanlar  -> 'Avropa'
- ölkə kodu JP, CN, IN, SG olanlar      -> 'Asiya'
- qalanları                             -> 'Diger'
Hər WHEN-də bir neçə OR yazmadan həll edin.
Sütunlar: CITY, COUNTRY_ID, QITE


Task 5.
Şirkət il sonu bonusu verir:
- 80-ci şöbənin işçilərinə maaşın 10%-i
- 60-cı şöbənin işçilərinə maaşın 15%-i
- qalan bütün işçilərə maaşın 5%-i
HR.EMPLOYEES cədvəlindən hər işçinin bonusunu hesablayın.
Sütunlar: FIRST_NAME, DEPARTMENT_ID, SALARY, BONUS
Ən böyük bonus yuxarıda olsun.


Task 6. Səhvləri tapın
Aşağıdakı sorğuda 3 səhv var. Məqsəd:
- maaşı 15000-dən çox olanlara 'Yuksek'
- maaşı 5000-dən çox olanlara 'Orta'
- qalanlarına 'Asagi' yazmaqdır.
Səhvləri düzəldin, düzgün sorğunu yazın və şərhlə qeyd edin ki, hər səhv nə idi.
Diqqət: səhvlərdən biri xəta vermir, sadəcə nəticəni səhv edir.

SELECT FIRST_NAME, SALARY,
       CASE
           WHEN SALARY > 5000  THEN 'Orta'
           WHEN SALARY > 15000 THEN 'Yuksek'
           ELSE 0
       END AS 'Seviyye'
FROM HR.EMPLOYEES;


Task 7.
HR.EMPLOYEES cədvəlindən hər işçinin şirkətdəki rolunu göstərin.
Şərtləri məhz bu sırada yoxlayın:
1) MANAGER_ID boşdursa                            -> 'Direktor'
2) MANAGER_ID 100-dürsə                           -> 'Direktorun komandasi'
3) JOB_ID 'MAN' və ya 'MGR' ilə bitirsə           -> 'Menecer'
4) qalanları                                      -> 'Isci'
Sütunlar: FIRST_NAME, JOB_ID, MANAGER_ID, ROL


Task 8.
COMMISSION_PCT işçinin maaşının neçə faizi qədər komissiya aldığını göstərir (məsələn 0.2 = 20%).
HR.EMPLOYEES cədvəlindən hər işçi üçün hesablayın:
- ILLIK_KOMISSIYA: bir ildə alınan komissiya = SALARY * COMMISSION_PCT * 12
- ILLIK_GELIR: illik maaş (SALARY * 12) və illik komissiyanın cəmi
Komissiyası olmayan işçilərdə ILLIK_KOMISSIYA 0 olmalıdır, ILLIK_GELIR isə boş qalmamalıdır.
NVL ilə həll edin.
Sütunlar: FIRST_NAME, SALARY, COMMISSION_PCT, ILLIK_KOMISSIYA, ILLIK_GELIR
Ən böyük illik gəlir yuxarıda olsun.


============================== ÇƏTİN ==============================

Task 9.
HR.EMPLOYEES və HR.JOBS cədvəllərini birləşdirin.
Hər işçinin maaşının öz vəzifəsinin maaş aralığında harada olduğunu göstərin.
Şərtləri məhz bu sırada yoxlayın:
1) maaş vəzifənin minimum maaşına (MIN_SALARY) bərabərdirsə   -> 'Minimumda'
2) maaş vəzifənin maksimum maaşına (MAX_SALARY) bərabərdirsə  -> 'Maksimumda'
3) maaş minimum və maksimumun tam ortasından azdırsa           -> 'Asagi yarida'
4) qalanları                                                   -> 'Yuxari yarida'
Ortanı belə hesablayın: (MIN_SALARY + MAX_SALARY) / 2
Sütunlar: FIRST_NAME, JOB_TITLE, SALARY, MIN_SALARY, MAX_SALARY, MOVQE


Task 10.
HR.EMPLOYEES, HR.DEPARTMENTS və HR.LOCATIONS cədvəllərini birləşdirin.
Bütün işçilər nəticədə olmalıdır, şöbəsi olmayan işçi də.
Hər işçi üçün iki sütun hesablayın:
- SOBE: şöbənin adı. Şöbəsi yoxdursa 'Sobesiz'. Bu sütunu NVL ilə yazın.
- OFIS: şöbəsi yoxdursa 'Melum deyil', şöbəsi Seattle şəhərindədirsə 'Bas ofis',
  qalanları 'Filial'.
Sütunlar: FIRST_NAME, LAST_NAME, SOBE, OFIS
Qeyd: OFIS sütununda şərtlərin sırası nəticəyə təsir edir, yoxlayın ki,
şöbəsi olmayan işçi 'Filial' alınmasın.
