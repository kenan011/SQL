Task 6. Səhvləri tapın
Aşağıdakı sorğuda 3 səhv var. Məqsəd: komissiyası olmayanlara 'Yoxdur', komissiyası 0.25-dən böyük olanlara 'Yuksek komissiya', qalan komissiyalılara 'Normal komissiya' yazmaqdır. Səhvləri düzəldin, düzgün sorğunu yazın və şərhlə qeyd edin ki, hər səhv nə idi.
Diqqət: səhvlərdən biri xəta vermir, sadəcə nəticəni səhv edir.

SQL
SELECT FIRST_NAME, COMMISSION_PCT,
       CASE
           WHEN COMMISSION_PCT = NULL  THEN 'Yoxdur'
           WHEN COMMISSION_PCT > 0.10  THEN 'Normal komissiya'
           WHEN COMMISSION_PCT > 0.25  THEN 'Yuksek komissiya'
           ELSE 0
       END AS 'Komissiya novu'
FROM HR.EMPLOYEES;

Task 8. Səhvləri tapın
Aşağıdakı sorğuda 3 səhv var. Məqsəd: IT və Finance şöbələrində işləyən işçilərin adını və maaşını göstərməkdir. Səhvləri düzəldin, düzgün sorğunu yazın və şərhlə qeyd edin ki, hər səhv nə idi.
Diqqət: səhvlərdən biri xəta vermir, sadəcə nəticəni əskik edir.

SQL
SELECT FIRST_NAME, SALARY
FROM HR.EMPLOYEES
WHERE DEPARTMENT_ID = (SELECT DEPARTMENT_ID, LOCATION_ID
                       FROM HR.DEPARTMENTS
                       WHERE DEPARTMENT_NAME IN ('it', 'Finance')
                       ORDER BY DEPARTMENT_ID);
