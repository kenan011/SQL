SQL DƏRS 4: EV TAPŞIRIĞI
Mövzu: SELF JOIN, IN ilə subquery

Bütün tapşırıqlar FreeSQL-də HR cədvəlləri üzərində yazılır.
Cədvəl adını həmişə HR. ilə yazın, məsələn: HR.EMPLOYEES.
Hər sorğunu işlədib nəticəsini yoxlayın, sonra hamısını bir .sql faylında
öz qovluğunuzdakı ders_04 qovluğuna yükləyin.
Hər sorğunun üstündə şərh kimi tapşırığın nömrəsini yazın: -- Task 1

İstifadə olunan cədvəllər:
HR.EMPLOYEES     işçilər
HR.DEPARTMENTS   şöbələr
HR.JOBS          vəzifələr

HR.EMPLOYEES-də MANAGER_ID sütunu işçinin menecerinin EMPLOYEE_ID-sini saxlayır.
Menecer də HR.EMPLOYEES cədvəlində olan bir işçidir. Ona görə işçi ilə menecerini
birləşdirmək üçün HR.EMPLOYEES cədvəli öz-özü ilə birləşdirilir (SELF JOIN).

Tapşırıqda "Sütunlar" yazılıbsa, nəticədə məhz bu sütunlar və bu adlar olmalıdır.


============================== ASAN ==============================

Task 1.
HR.EMPLOYEES cədvəlini öz-özü ilə birləşdirin.
Hər işçinin adını və soyadını, yanında isə menecerinin adını və soyadını göstərin.
Yalnız meneceri olan işçilər görünsün.
Sütunlar: FIRST_NAME, LAST_NAME, MENECER_ADI, MENECER_SOYADI


Task 2.

Sütunlar: FIRST_NAME, LAST_NAME, MENECER_ADI, MENECER_SOYADI
Şərhdə yazın: Task 1-də neçə sətir, Task 2-də neçə sətir çıxdı və niyə fərqlidir?


Task 3.

Şöbə nömrələrini əl ilə yazmayın, IN ilə subquery istifadə edin.
Sütunlar: FIRST_NAME, LAST_NAME, DEPARTMENT_ID

Task 6.

Task 7.
HR.JOBS cədvəlində hər vəzifənin minimum maaşı (MIN_SALARY) yazılıb.
Minimum maaşı 10000 və daha çox olan vəzifələrdə işləyən işçiləri göstərin.
IN ilə subquery istifadə edin.
Sütunlar: FIRST_NAME, LAST_NAME, JOB_ID, SALARY


Task 8. Səhvləri tapın
Aşağıdakı sorğuda 3 səhv var. Məqsəd: Sales və IT şöbələrində işləyən işçilərin
adını və soyadını göstərməkdir.
Səhvləri düzəldin, düzgün sorğunu yazın və şərhlə qeyd edin ki, hər səhv nə idi.
Diqqət: səhvlərdən biri xəta vermir, sadəcə nəticəni əskik edir.

SELECT FIRST_NAME, LAST_NAME
FROM HR.EMPLOYEES
WHERE DEPARTMENT_ID = (SELECT DEPARTMENT_ID, DEPARTMENT_NAME
                       FROM HR.DEPARTMENTS
                       WHERE DEPARTMENT_NAME IN ('sales', 'IT'));
