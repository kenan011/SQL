SQL DƏRS 2: EV TAPŞIRIĞI
Mövzu: GROUP BY, HAVING, JOIN

Bütün tapşırıqlar FreeSQL-də HR cədvəlləri üzərində yazılır.
Cədvəl adını həmişə HR. ilə yazın, məsələn: HR.EMPLOYEES.
Dərsdə özünüz yaratdığınız cədvəllərdən (DEMO_EMPLOYEES, DEMO_DEPARTMENTS) istifadə etməyin.
Hər sorğunu işlədib nəticəsini yoxlayın, sonra hamısını bir .sql faylında
öz qovluğunuzdakı ders_02 qovluğuna yükləyin.
Hər sorğunun üstündə şərh kimi tapşırığın nömrəsini yazın: -- Task 1

İstifadə olunan cədvəllər:
HR.EMPLOYEES     işçilər
HR.DEPARTMENTS   şöbələr
HR.JOBS          vəzifələr
HR.LOCATIONS     ofislər (ünvan, şəhər, ölkə)

Cədvəllər bu sütunlarla birləşir:
HR.EMPLOYEES.DEPARTMENT_ID  = HR.DEPARTMENTS.DEPARTMENT_ID
HR.EMPLOYEES.JOB_ID         = HR.JOBS.JOB_ID
HR.DEPARTMENTS.LOCATION_ID  = HR.LOCATIONS.LOCATION_ID

Sütunlara baxmaq üçün: SELECT * FROM HR.LOCATIONS;
Tapşırıqda "Sütunlar" yazılıbsa, nəticədə məhz bu sütunlar və bu adlar olmalıdır.

Task 1.

Ən çox işçisi olan menecer yuxarıda olsun.

Sütunlar: COUNTRY_ID, OFIS_SAYI
Ən çox ofisi olan ölkə yuxarıda olsun.


Task 3.

Sütunlar: FIRST_NAME, LAST_NAME, JOB_TITLE


============================== ORTA ==============================

Task 4.
HR.EMPLOYEES cədvəlindən orta maaşı 8000-dən çox olan şöbələri tapın.
Orta maaşı vergüldən sonra 2 rəqəmə qədər yuvarlaqlaşdırın.
Sütunlar: DEPARTMENT_ID, ORTA_MAAS


Task 5.
HR.EMPLOYEES cədvəlindən yalnız maaşı 3000 və daha çox olan işçiləri götürün.
Hər şöbədə belə işçilərdən neçə nəfər olduğunu hesablayın.
Yalnız 3-dən çox belə işçisi olan şöbələri göstərin.
Sütunlar: DEPARTMENT_ID, ISCI_SAYI


Task 6.
HR.EMPLOYEES və HR.JOBS cədvəllərini birləşdirin.
Hər vəzifənin adı üzrə neçə işçi olduğunu göstərin.
Sütunlar: JOB_TITLE, ISCI_SAYI
Ən çox işçisi olan vəzifə yuxarıda olsun.


Task 7.
HR.LOCATIONS və HR.DEPARTMENTS cədvəllərindən istifadə edin.
Heç bir şöbəsi olmayan ofislərin şəhərini və ölkə kodunu göstərin.
Sütunlar: CITY, COUNTRY_ID


Task 8. Səhvləri tapın
Aşağıdakı sorğuda 3 səhv var. Məqsəd: hər vəzifənin adını və orta maaşını göstərmək,
yalnız orta maaşı 10000-dən çox olan vəzifələri saxlamaqdır.
Səhvləri düzəldin, düzgün sorğunu yazın və şərhlə qeyd edin ki, hər səhv nə idi.

SELECT J.JOB_TITLE, E.LAST_NAME, AVG(E.SALARY) AS ORTA_MAAS
FROM HR.EMPLOYEES E
JOIN HR.JOBS J ON E.JOB_ID = JOB_ID
WHERE AVG(E.SALARY) > 10000
GROUP BY J.JOB_TITLE;


============================== ÇƏTİN ==============================

Task 9.

Orta maaşı tam ədədə qədər yuvarlaqlaşdırın.
Yalnız 5-dən çox işçisi olan şəhərləri göstərin.
Sütunlar: CITY, ISCI_SAYI, ORTA_MAAS
Ən çox işçisi olan şəhər yuxarıda olsun.


Task 10.
HR.DEPARTMENTS və HR.EMPLOYEES cədvəllərindən istifadə edin.
Bütün şöbələrin adını və hər şöbədə neçə işçi olduğunu göstərin.
İşçisi olmayan şöbələr də siyahıda olmalıdır və onlarda işçi sayı 0 göstərilməlidir.
Sütunlar: DEPARTMENT_NAME, ISCI_SAYI
Nəticəni işçi sayına görə azalan, eyni sayda olanları şöbə adına görə (A-dan Z-yə) sıralayın.
